# IaCGuardian - Module 1

## Module Name
Infrastructure Parsing & Asset Dependency Modelling

## Description
This module analyzes Infrastructure as Code (IaC) resources by parsing cloud infrastructure assets, identifying dependencies, calculating risk scores, and presenting the information through an interactive Shiny dashboard.

## Technologies Used
- R Programming
- Shiny
- shinydashboard
- ggplot2
- DT
- dplyr

## Dataset
- iac_dataset_1000.csv

## Features
- Infrastructure Asset Inventory
- Asset Dependency Modelling
- Risk Score Analysis
- Interactive Dashboard
- Data Visualization
- Resource Distribution
- K-Means Clustering
- Exportable Data Table
